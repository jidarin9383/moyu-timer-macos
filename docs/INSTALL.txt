摸了个鱼 — 安装与首次打开说明

适用于 macOS 13 及以上版本的 Apple Silicon Mac。

一、安装
1. 将「摸了个鱼.app」拖入 Applications（应用程序）。
2. 从「应用程序」中打开。启动后请在菜单栏寻找鱼形图标。
3. 升级前请先退出旧版；原有统计数据和分类设置会保留。

二、首次打开时的安全提示
当前版本未经过 Apple 公证。首次打开可能提示无法验证开发者，或 Apple 无法检查此 App 是否包含恶意软件。

仅当你确认安装包来自本项目的 GitHub Releases、且未遭篡改时，按以下步骤操作：
1. 先尝试打开一次 App；若被阻止，关闭提示。
2. 打开「系统设置」→「隐私与安全性」，向下找到「安全性」。
3. 找到「摸了个鱼」被阻止的提示，点击「仍要打开」。
4. 按系统要求使用密码或 Touch ID 确认，并在后续提示中点击「打开」。

不同 macOS 版本的提示文字可能略有差异。受单位管理的 Mac 可能无法使用此选项，请联系管理员。
如果提示 App 已损坏或会损坏电脑，请停止安装，重新从项目 Releases 下载并核对 SHA-256；仍有问题请联系开发者。

三、网站统计权限
应用计时无需额外权限。网站统计需在 App 内点击「授权」：Firefox 使用辅助功能权限，其他已适配浏览器使用自动化权限。
